# Ponder Puzzlers tile set — SVG

Every sprite of the game's original artwork as a scalable SVG (266 files), plus:

- `sheet.svg` — all sprites on one sheet, 16 per row, in atlas order; each sprite is a nested `<svg id="name">`.
- `index.html` — open in a browser to browse them with names.

Generated by `art/svgexport.py`, which runs the same drawing code as `art/generate.py` (the bitmap atlas the
game uses) against an SVG back end, so the two match. Drawing space is 192×192 units; files display at 48×48 by
default. Regenerate with `python3 art/svgexport.py` (needs `fonttools` for the hint tile's "?" outline).

Names: `tile_XX` (Lynx tile codes, spec doc 03; `tile_34`/`tile_35` are the extended-mode north/west thin walls),
animated tiles `force_<dir>_<frame>`, `force_R_*`, `teleport_*`, `fire_*`, `water_*`, `exit_*`, `toggleopen_*`,
`toggleclosed_*`; creatures `obj_<type>_<dir>_<frame>` (types: 2 bug, 3 paramecium, 4 fireball, 5 glider, 6 ball,
8 tank, 9 walker, 10 blob, 11 teeth; dirs 0 N, 1 E, 2 S, 3 W), `obj_7` block; the hero `hero_<dir>_<frame>`,
`heropush_<dir>`; effects `fx_explode_*`, `fx_smoke_*`, `fx_splash_*`.
